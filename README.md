# OSEG Seguros — novo site institucional

Site estático responsivo: `index.html`, `style.css`, `script.js` e `assets/`.

## Publicação
GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.

## Antes de publicar no domínio oficial
Validar fotos e logotipo oficiais, consentimento para uso de imagens e depoimentos, telefone de WhatsApp de cotações, Política de Privacidade/LGPD e integração da Korax. O formulário de cotação em etapas abre o WhatsApp comercial informado pelo site e não registra leads em servidor.

Fontes institucionais: https://osegseguros.com.br/quemsomos/ e https://osegseguros.com.br/unidades/.
